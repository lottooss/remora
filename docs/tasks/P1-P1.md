## Goal

One TypeScript source of truth for every message in [RCP/1](../specs/rcp-v1.md) and [RLY/1](../specs/relay-v1.md): exported types, zod schemas for untrusted input, encoders/decoders with size limits, and the vectors that the Kotlin implementation will also pass.

## Inputs

Frozen specs, `docs/spikes/P0-S1.md` (real dsh shapes that influence RCP), `conformance/README.md`.

## Deliverables

- `packages/protocol/src/rcp/*`: envelope, errors, every method's params/result, stream items, `SessionEvent` union with unknown-value fallbacks; a method registry `{ name, kind: 'unary'|'stream', mutating, params, result, item? }`.
- `packages/protocol/src/relay/*`: control frame schemas, binary data-frame encode/decode (28-byte header), close codes, error codes.
- `packages/protocol/src/limits.ts`: `MAX_RCP_MESSAGE_BYTES = 49152`, `MAX_DATA_FRAME_BYTES = 65536`, etc. (protocol constants, fixed).
- Vectors: `conformance/vectors/rcp/**`, `conformance/vectors/relay/**` generated by `packages/protocol/scripts/gen-vectors.ts` and committed.
- Runtime-neutral: runs in Node 22+/24 and workerd (no `Buffer`, no `node:*` imports).

## Acceptance

- [ ] Every method in RCP/1 §11 is in the registry; a test asserts the registry equals the spec table.
- [ ] Decoders reject oversize input before parsing JSON; unknown enum values decode to fallbacks; unknown fields ignored.
- [ ] ≥ 95 % line coverage; vectors validate against the conformance schema.
- [ ] `import '@remora/protocol'` works from the relay (workerd) and the host (Node).

## Constraints

- No dependency beyond `zod`. No I/O.

## Stop and report

- Any need to change a frozen spec.

## Verify

```sh
pnpm -F @remora/protocol run typecheck && pnpm -F @remora/protocol test && pnpm run conformance:check
```
