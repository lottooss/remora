## Goal

Inspect the agent's work on the phone: workspace tree, file viewer with syntax highlighting and line paging, changed-files list, and a readable diff viewer.

## Inputs

RCP/1 §9, blueprint §10.6, §11.7. Develop against testkit transcripts until P4-H2 merges.

## Deliverables

- File tree (lazy directory loading, size badges, binary indicator), file viewer (line-paged `files.read`, monospace, soft wrap toggle, syntax highlighting for common languages, search within loaded text), changes tab (`diffs.status` with counts), diff viewer (unified; side-by-side on wide screens; hunk paging), live refresh from `files.changes`.
- `core:ui` reusable `CodeView` and `DiffView` components with previews.

## Acceptance

- [ ] A 20,000-line file pages smoothly; a 3,000-line diff renders without jank on the owner's phone.
- [ ] UI tests for tree, viewer, diff, empty and error states.

## Verify

```sh
cd apps/android && ./gradlew testDebugUnitTest assembleDebug
```
