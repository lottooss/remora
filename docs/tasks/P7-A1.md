## Goal

`SecureKeyStorage(context)` encrypts pairing keys with a random key generated per process and never saved, so every app restart loses every pairing, and nothing uses the Android Keystore. Replace it with Tink backed by a Keystore master key, as Crypto/1 §9 requires.

## Deliverables

- `AndroidKeysetManager` with master key `android-keystore://remora_master_v1`, AEAD keyset in app-private prefs; per-host key material encrypted with it.
- Instrumented test (androidTest): save → create a NEW storage instance → read back equal; wipe removes it.
- Workflow `android-instrumented.yml` (owner approves): emulator via `reactivecircus/android-emulator-runner`, runs `connectedDebugAndroidTest`.
