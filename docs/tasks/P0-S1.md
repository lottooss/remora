## Goal

Prove, with a throwaway bundle installed into a real npm-installed dsh (`0.1.5-rc.3`), that an out-of-tree Cordis plugin can do everything the DshAdapter needs, and record the exact wire types and fixtures that later tasks will code against. Answers open questions Q1–Q4 and Q10 in [dsh-integration.md §8](../upstream/dsh-integration.md#8-open-questions-owned-by-spikes).

## Inputs

[dsh-integration.md](../upstream/dsh-integration.md), [blueprint §8.4](../blueprint.md#84-dshadapter-how-remora-reaches-dsh), upstream `docs/api-gateway.md`, `packages/api/session-controller/README.md`, `apps/cli/reference/README.md`. Fetch sources with `node scripts/fetch-upstream.mjs`.

## Deliverables

- `spikes/p0-s1-dsh-adapter/`: a minimal bundle package (`dsh.bundle.patch`, one plugin row) that on load:
  1. calls `ctx.typertGateway.invoke({ namespace: 'session', method: 'list', args: … })` and logs the item count;
  2. creates a workspace + session in a temp directory, prompts it (with `DEEPSEEK_BASE_URL` pointing at `@deepseek-ai/dsh-llm-mock-server` scripted to reply and call one tool), and consumes `session/follow` from the start and again from a mid-stream cursor;
  3. registers an exact Connection Fetch route `GET /api/remora/ping` and checks it requires the browser cookie;
  4. writes and reads an owner-scoped `ctx.credentials` record and a `ctx.storage.domain` document.
- Recorded fixtures: `packages/host/test/fixtures/dsh-0.1.5-rc.3/follow-*.jsonl` (raw follow frames: snapshot, durable events incl. tool call/result, live assistant frames, resume from cursor), `list.json`, `prompt-duplicate.json`.
- `docs/spikes/P0-S1.md`: findings per question with evidence (commands, versions, outputs), exact TypeScript request/response types for every endpoint in the blueprint table, recommended adapter shape, and gaps.
- `docs/upstream/dsh-integration.md` §8/§9 updated.

## Acceptance

- [ ] Q1–Q4 each answered **yes / no + workaround** with evidence.
- [ ] Fixtures cover: opening snapshot, durable user/assistant/tool events, live frames and their settlement, resume after `afterSeq`, duplicate `requestId` prompt.
- [ ] Install/uninstall procedure for a local bundle documented and repeatable on Windows (`dsh plugin --profile remora-dev add ./spikes/p0-s1-dsh-adapter`).
- [ ] Q10 answered: linked checkout vs packed tarball, with evidence of which `@deepseek-ai/cordis` / `@deepseek-ai/schemastery` copies the plugin resolves at runtime; the chosen install form is written into `packages/host/README.md`.

## Constraints

- No real DeepSeek API key; use the mock server. Never modify files under the dsh installation or the owner's existing `web` profile — use a throwaway `remora-dev` profile.

## Stop and report

- The gateway rejects in-process calls from an out-of-tree plugin, or strict descriptors are missing in npm installs.
- Follow cannot resume from a cursor.

## Verify

Commands and outputs are recorded in `docs/spikes/P0-S1.md`; a reviewer can rerun them in under 15 minutes.
