## Goal

Swarm agents must not be able to weaken the gates. Turn on GitHub branch protection for `main` using the `.github/CODEOWNERS` file added with this plan.

## Inputs

- .github/CODEOWNERS
- docs/SWARM.md §4

## Deliverables

- GitHub → Settings → Branches → rule for `main`: require a pull request; require approval from Code Owners; require status checks `ci` and `android` (later also `real-dsh`, `real-dsh-e2e`, `conformance-strict`, `no-stubs`); do not allow bypass.

## Acceptance

- [ ] A test PR touching `scripts/check-conformance.mjs` shows "Review required from code owners".

## Who

Only the repository owner does this task. Swarm agents may prepare instructions but never tick its boxes.

## Stop and report

- See docs/SWARM.md §6.
