## Goal

`new PersistentDeviceRegistry()` without a path is memory-only and `InMemoryNotifyPrefsStore` forgets preferences, so every restart unpairs every phone. Persist both.

## Inputs

- docs/SWARM.md (whole file)
- AGENTS.md
- docs/specs/crypto-v1.md §3, §9, §10
- packages/host/src/devices/persistent-registry.ts

## Deliverables

- Store the device registry (public keys, names, revoked flags) and per-device `devicePsk`/`pushKey` in the dsh credentials record `remora/devices` (one record, written atomically with `modifyRecord`). Remove the file-path mode or keep it for tests only.
- Store notify prefs per device in the same record or `remora/notify-prefs`.
- Revocation deletes the device secrets in the same write.

## Acceptance

- [ ] Unit tests: pair → re-create registry from the same credentials store → device still admitted; revoke survives restart.
- [ ] Extend tests/real-dsh (owner-approved change) OR add a host apply test proving persistence across two mounts with the same credentials store.
