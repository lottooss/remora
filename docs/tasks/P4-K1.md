## Goal

Start new work from the phone: choose a registered workspace or browse the host's allowed roots, optionally create a folder, pick a model, type the first prompt, land in the conversation.

## Inputs

RCP/1 §6, blueprint §10.6, §11.6. Develop against testkit transcripts until P4-H1 merges.

## Deliverables

- Workspace picker (registered workspaces, `remoteAllowed` badge, recent first), root browser (breadcrumbs, folders only by default, create folder dialog with validation), model picker reuse, first-prompt composer; `sessions.create` with `requestId`, then `sessions.prompt`.
- Empty states: no roots configured (explain how to add `remoteRoots` on the PC), remote start disabled by policy.

## Acceptance

- [ ] From the owner's phone: create a folder in a root, start a session, see the first answer stream.
- [ ] UI tests for picker, browser, errors (`forbidden`, `not_found`).

## Verify

```sh
cd apps/android && ./gradlew testDebugUnitTest assembleDebug
```
