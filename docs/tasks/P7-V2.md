## Goal

Replace the placeholder RCP and relay vector files with generated valid and invalid examples for every method, envelope, session event, limit, and relay frame, and run them in both languages.

## Inputs

- docs/SWARM.md (whole file)
- AGENTS.md
- docs/specs/rcp-v1.md, docs/specs/relay-v1.md
- packages/protocol/src (zod schemas, RCP_METHODS)

## Deliverables

- `packages/protocol/scripts/gen-vectors.ts` producing one file per method in `RCP_METHODS` (≥ 2 valid, ≥ 1 invalid), envelope, session-events (every kind + unknown fallback), limits (boundary sizes), relay data-frame and control frames.
- TS test decodes every case with the zod schemas; Kotlin test decodes every case with `:core:protocol` codecs and agrees on valid/invalid.

## Acceptance

- [ ] `--strict` passes for `rcp/*` and `relay/*`; stale method files (e.g. for removed methods) deleted.

## Evidence rules

- Follow docs/SWARM.md §1 and §7: red CI run first, then green; both links in the PR and the handoff.
- Anything needing a phone, cloud account, secret, or signing key stays unticked with `OWNER-PENDING`.

## Stop and report

- See docs/SWARM.md §6.

## Verify

```sh
pnpm run conformance:check -- --strict
pnpm -F @remora/protocol test
cd apps/android && ./gradlew :core:protocol:test
```
