## Goal

Add an automated test that installs the real `@remora/host` into a real, pinned dsh (`upstream.lock.json`) inside a temporary `DSH_HOME`, boots it against a local relay, and asserts the plugin starts, reaches the relay, and keeps the same host identity across a restart. Today this test must FAIL because dsh crashes on boot (`cannot get property "typertGateway" without inject`). It becomes the gate that P7-H1, P7-H2 and P7-H3 turn green.

## Inputs

- docs/SWARM.md (whole file)
- AGENTS.md
- docs/upstream/dsh-integration.md §2 (profiles, `dsh plugin`)
- spikes/p0-s1-dsh-adapter/ (how a bundle was installed and booted against real dsh)
- packages/host/test/fixtures/dsh-0.1.5-rc.3/report.json
- apps/relay/README.md (wrangler dev)
- packages/testkit/src (E2eEnvironment: how it starts wrangler dev)

## Deliverables

- `tests/real-dsh/boot.spec.ts` (Vitest, own `tests/real-dsh/vitest.config.ts`, timeout ≥ 5 min):
  - 1. build `@remora/host`; create temp `DSH_HOME`; `dsh --profile remora-e2e --from-default-profile web --help` (or the documented way to initialize the web template without booting);
  - 2. `dsh plugin --profile remora-e2e add <repo>/packages/host` (after P7-H8 lands, switch to the packed tarball);
  - 3. start `wrangler dev` for `apps/relay` on a free port with `.dev.vars` `REMORA_ENROLL_SECRET=<random test value>`;
  - 4. write the profile `cordis.patch.yml` `remora` row pointing at that relay; pass `REMORA_RELAY_ENROLL_SECRET` to dsh through its environment;
  - 5. boot `dsh --profile remora-e2e --no-open --port <free>`, collect stdout/stderr;
  - 6. assert: process alive after 45 s; output contains `remora: host started`; output contains `remora: relay ready` (P7-H3 adds this info line); no line matching `/remora:.*(error|failed)/i`; capture the logged host id;
  - 7. stop dsh (SIGTERM, then kill after 10 s), boot again, assert the same host id is logged (P7-H2);
  - 8. always tear down dsh, wrangler, temp dirs (assert nothing left listening).
- Root script `test:real-dsh` in `package.json`.
- `.github/workflows/real-dsh.yml`: ubuntu-latest + windows-latest matrix, Node from `.node-version`, `pnpm install --frozen-lockfile`, `pnpm test:real-dsh`, upload the collected dsh/relay logs as an artifact on failure. The job is **not required** yet (P7-V3 makes it required).
