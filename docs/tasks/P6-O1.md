## Goal

Ship v1.0.0: a complete operations guide the owner can follow from zero, a signed release APK, a CI compatibility matrix against dsh npm `latest` and `next`, versioning, and a changelog.

## Inputs

All docs, reports from P6-T1/P6-T2, `docs/runbooks/operations.md`.

## Deliverables

- `docs/runbooks/operations.md` complete: relay deploy, secrets, Firebase, host install/upgrade/uninstall, service, phone install, pairing, revocation, troubleshooting, backup/restore of the relay (none needed) and host identity.
- Release signing: keystore generated by the owner (never committed), Gradle signing config reading env vars, CI job producing an unsigned artifact + local signing instructions.
- `.github/workflows/dsh-compat.yml`: nightly typecheck + adapter tests + e2e smoke against `@deepseek-ai/dsh@latest` and `@next`.
- Versioning policy (semver for app, host, relay; protocol versions separate), `CHANGELOG.md`, tag `v1.0.0` (owner approves).

## Acceptance

- [ ] A fresh reader completes the full setup from the guide on a second Windows account (dry run by an agent + owner confirmation).
- [ ] Compat workflow green for `latest`.
