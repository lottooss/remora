## Goal

The lock screen is a button labelled "Unlock (placeholder)" that unlocks without any authentication. Use BiometricPrompt (BIOMETRIC_STRONG, or DEVICE_CREDENTIAL when the host policy allows).

## Deliverables

- `BiometricAuthenticator` interface in `:core:security` with a real implementation using `androidx.biometric.BiometricPrompt`; `AppLockGate.unlock()` reachable only from the authenticator success callback.
- Lock screen with a real prompt; no bypass path; re-lock after 5 min background (existing logic).
