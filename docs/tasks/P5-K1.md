## Goal

Receive and show notifications reliably and privately: FCM token registration per host, decryption in the messaging service, channels, deep links behind the app lock, and preference screens.

## Inputs

ADR-0006, blueprint §10.5, Crypto/1 §8, RLY/1 §5 (`push.token`), RCP/1 §10.

## Deliverables

- Firebase setup gated on `apps/android/app/google-services.json` (git-ignored); build still succeeds without it (push disabled, banner in settings).
- `RemoraMessagingService`: decrypt with the host's push key, map `kind` to channel, render, deep-link (`remora://session/<id>`, `remora://approvals/<id>`), handle `host_offline` from local host data; drop undecryptable messages silently (count in diagnostics).
- Token lifecycle: register on pairing and on refresh via `push.token` for every paired host.
- Settings: per-host notification prefs (RCP), host-offline alerts (relay), Android permission prompt for notifications (API 33+).

## Acceptance

- [ ] With a Firebase project configured by the owner, approvals/questions/turn-done/turn-error/host-offline notifications arrive on the owner's phone with the app killed.
- [ ] Tapping opens the right screen after unlock.

## Stop and report

- The owner has not created the Firebase project (the task can finish everything else and mark delivery verification pending).
