## Goal

The host-side enforcement layer of [ADR-0007](../adr/0007-biometric-gated-parity.md): path canonicalization and root containment (Windows-hard), the deterministic risk classifier, approval signature verification, permission-change gating, and per-device rate limits.

## Inputs

ADR-0007, blueprint §8.7, Crypto/1 §7, threat model T10–T14, T23–T25.

## Deliverables

- `policy/paths.ts`: `canonicalize(path)` (realpath, long paths, case folding on Windows, 8.3 expansion via realpath, trailing dot/space handling, NUL rejection, UNC/device path rejection) and `contains(root, path)`; roots resolved at load.
- `policy/risk.ts`: classifier with configurable low-risk tool set and destructive pattern list (commands parsed with a shell-aware tokenizer for bash and PowerShell); unknown tools → `high`.
- `policy/signature.ts`: verify answers via `@remora/crypto` (digest, canonical message, DER P-256 high-S, freshness, single-use store).
- `policy/limits.ts`: token buckets per device (20 req/s burst, 5 mutating/s, 10 streams).
- `policy/index.ts`: `PolicyGuard` interface consumed by RCP methods.
- Test matrix: path escapes on Windows (junctions via `mklink /J`, symlinks when permitted, 8.3 names, UNC, `\\?\`) and POSIX; classifier table tests (≥ 60 cases); signature positive/negative vectors.

## Acceptance

- [ ] All threat-model path-escape cases denied; legitimate nested paths allowed.
- [ ] High-risk approvals without a valid signature are refused and remain pending.
- [ ] Classifier decisions are pure functions with table tests.

## Constraints

- Deny on any canonicalization error. No network or dsh access from `policy/`.

## Stop and report

- Windows canonicalization cannot be made reliable for a case in the matrix (document and default-deny).

## Verify

```sh
pnpm -F @remora/host test -- policy
```
