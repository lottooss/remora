## Goal

Make the host always available on the owner's Windows PC without admin rights, per [ADR-0009](../adr/0009-always-on-host.md) and the mechanism chosen in P0-S6, and keep the PC awake while agents work.

## Inputs

ADR-0009, `docs/spikes/P0-S6.md`, blueprint §8.11, §14 (`remora doctor`).

## Deliverables

- `apps/cli`: `remora service install [--dsh-version <v>] [--port 7717] [--profile remora]`, `uninstall`, `status`, `logs [-f]`, `host run` (supervisor: pinned dsh runtime under `%LOCALAPPDATA%\Remora\runtime`, restart with capped backoff, daily log rotation keeping 14 days, graceful stop), `doctor` (Node/dsh versions, profile present, bundle installed, relay reachable, service state, keep-awake support, power-settings hints).
- `packages/host/src/platform/keep-awake-*.ts` (win32 per P0-S6, darwin `caffeinate`, linux `systemd-inhibit`), driven by `agent/status` with a 2-minute grace period and released on dispose.
- Operations runbook sections for install/uninstall/upgrade/logs.

## Acceptance

- [ ] On the owner's PC: install → sign out/in → host online at the relay within 60 s, no visible window; uninstall removes every trace.
- [ ] `powercfg /requests` shows the request only while an agent runs (+ grace).
- [ ] `remora doctor` reports actionable failures for each check.

## Constraints

- Never require elevation; never modify system power settings.

## Verify

```sh
pnpm -F @remora/cli test && pnpm -F @remora/host test -- platform
```
