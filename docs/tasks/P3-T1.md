## Goal

Turn the [threat model](../specs/threat-model.md) checklist into automated tests that run in CI, and report every mitigation's status.

## Inputs

Threat model §3 and §5, `@remora/testkit` adversary mode, Policy Guard and AnswerBridge.

## Deliverables

- `tests/security/*.spec.ts`: adversarial relay (flip/reorder/replay/drop/splice), pairing attacks, approval forgery/replay/digest mismatch/high-S, revoked device, path-escape matrix end to end through RCP, oversize and rate-limit behavior, log scans across host/relay logs captured in e2e.
- Threat model table updated: each row's Test column links to the test file and shows status.
- A CI job `security` (runs on every PR touching host, relay, crypto, protocol).

## Acceptance

- [ ] Every T-row applicable to P1–P3 has a passing automated test or a documented manual procedure.
- [ ] Log scans find no secrets or payload markers.

## Stop and report

- A mitigation cannot be tested automatically and has no manual procedure.

## Verify

```sh
pnpm test:security
```
