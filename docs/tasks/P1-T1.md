## Goal

A reproducible end-to-end environment on one machine and in CI: local relay (`wrangler dev`), a real dsh with the Remora bundle in a throwaway `remora-e2e` profile (isolated `DSH_HOME`), a scripted mock LLM, and a TypeScript fake phone that speaks RLY/1 + SC/1 + RCP/1.

## Inputs

All specs, `docs/spikes/P0-S1.md` (mock LLM usage), `packages/relay-link`, `packages/crypto`, `packages/protocol`.

## Deliverables

- `packages/testkit/src/device.ts`: `FakeDevice` (enroll, connect, pair, handshake, RCP client with typed methods and stream iterators).
- `packages/testkit/src/adversary.ts`: relay adversary mode (flip, drop, reorder, replay, splice) for security tests.
- `packages/testkit/src/env.ts`: starts/stops relay, mock LLM, dsh profile with temp `DSH_HOME`; collects logs; guaranteed teardown.
- `tests/e2e/*.spec.ts` (Vitest): smoke `hello`; placeholders for later phases.
- CI workflow job `e2e` (Linux; Windows job optional/nightly).

## Acceptance

- [ ] `pnpm test:e2e` runs green from a clean clone with no API keys in < 5 minutes.
- [ ] Teardown leaves no processes, ports, or temp dirs (checked by the harness).
- [ ] Logs from all three processes are attached to failures.

## Constraints

- Never touch the developer's real `~/.dsh`; always a temp `DSH_HOME`.

## Stop and report

- dsh cannot run with an isolated `DSH_HOME` or the mock LLM cannot drive tool calls.

## Verify

```sh
pnpm test:e2e
```
