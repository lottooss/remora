## Goal

A reusable, well-tested relay client for Node used by the host plugin and the testkit: connect, authenticate, reconnect with jitter, send/receive data frames, control requests with `rid` correlation, presence tracking, clean shutdown.

## Inputs

RLY/1 (frozen), Crypto/1 §4, `@remora/protocol` relay codecs, `@remora/crypto` relay-auth.

## Deliverables

- `RelayLink` class: `start()`, `stop()`, `sendData(peer, channel, payload)`, `request(controlFrame)`, events (`ready`, `data`, `presence`, `state`, `error`), backoff (0.5 s → 30 s, full jitter, reset on success), ping every 25 s, dead-peer detection at 60 s, `bufferedAmount` exposure for backpressure.
- Pluggable WebSocket factory (default `ws`) so tests can inject a fake.
- Tests against a fake relay and against `wrangler dev` (skipped when unavailable).

## Acceptance

- [ ] Reconnect storm test: 100 forced disconnects → no leaked sockets/timers, state machine consistent.
- [ ] `stop()` resolves within 1 s and leaves no handles (verified with `why-is-node-running`-style check).
- [ ] ≥ 90 % coverage.

## Constraints

- Does not parse SC/1 or RCP payloads. No logging of payloads or keys.

## Stop and report

- The protocol needs a frame type not in RLY/1.

## Verify

```sh
pnpm -F @remora/relay-link run typecheck && pnpm -F @remora/relay-link test
```
