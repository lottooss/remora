## Goal

The app never opens `interaction.follow`, `sessions.control`, or `workspaces.follow`, so approval requests never reach the phone and running/queue state is invisible.

## Inputs

- docs/SWARM.md (whole file)
- AGENTS.md
- apps/android/README.md
- docs/blueprint.md §10
- AGENTS.md §7.5
- docs/specs/rcp-v1.md §5, §6, §8
- apps/android/core/data/.../SyncEngine.kt, InteractionRepository.kt
- conformance/vectors/rcp/method-list.json (P7-C1)

## Deliverables

- `SyncEngine` opens all three streams when a host channel is ready and re-opens them after reconnect; feeds `InteractionRepository`, session control state, workspace list.
- JVM test: every RCP method string used in `src/main` of all modules exists in `method-list.json`.
- JVM test with a scripted `RcpClient`: a `requested` approval appears in `InteractionRepository.allPending`; `resolved` removes it.
