## Goal

The documented install (`pnpm -F @remora/host pack` → `dsh plugin add <tgz>`) cannot work: the tarball depends on `@remora/crypto`, `@remora/protocol`, `@remora/relay-link`, which are not published. Bundle them into the host build so the tarball is self-contained.

## Inputs

- docs/SWARM.md (whole file)
- AGENTS.md
- packages/host/package.json
- docs/upstream/dsh-integration.md Q10

## Deliverables

- Build `lib/index.js` with tsdown (or esbuild) bundling `@remora/*` and `qrcode`; keep `@deepseek-ai/cordis` and `@deepseek-ai/schemastery` as external peers; move `@remora/*` to devDependencies.
- README + operations runbook: the tarball install is the documented path.
- Update tests/real-dsh to install the tarball (coordinate: that path is protected; the owner approves the one-line change).

## Acceptance

- [ ] `npm pack --dry-run` / tarball `package.json` lists no `@remora/*` runtime dependency (paste).
- [ ] Installing the tarball into a clean temp `DSH_HOME` succeeds and `real-dsh` stays green.

## Evidence rules

- Follow docs/SWARM.md §1 and §7: red CI run first, then green; both links in the PR and the handoff.
- Anything needing a phone, cloud account, secret, or signing key stays unticked with `OWNER-PENDING`.
