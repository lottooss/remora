## Goal

Kotlin twins of `@remora/protocol` and `@remora/crypto` as pure-JVM modules that pass exactly the same conformance vectors, plus a cross-language handshake test in CI.

## Inputs

Frozen specs, `packages/protocol`, `packages/crypto`, `conformance/vectors/**`, `docs/spikes/P0-S4.md`.

## Deliverables

- `:core:protocol`: kotlinx.serialization models for RCP/1 and RLY/1 (sealed classes with `Unknown` fallbacks), codecs with size checks, data-frame header codec.
- `:core:crypto`: Noise IKpsk2 (BouncyCastle primitives), ids, relay-auth signing, pairing (QR parse, PSK, SAS), approval canonical message + digest, push open.
- `:core:model`: domain models used by features.
- JUnit runners that load `conformance/vectors/**` via a Gradle-configured path.
- CI: a job that runs the TypeScript responder and the Kotlin initiator against each other (script in `conformance/interop/`).

## Acceptance

- [ ] 100 % of vectors pass in Kotlin.
- [ ] Interop job green in CI.
- [ ] Modules have no Android dependency (`kotlin("jvm")`).

## Constraints

- BouncyCastle `bcprov-jdk18on` only for primitives; no reflection-based JSON.

## Stop and report

- Any vector that passes in TypeScript but whose spec reading differs in Kotlin.

## Verify

```sh
cd apps/android && ./gradlew :core:protocol:test :core:crypto:test
```
