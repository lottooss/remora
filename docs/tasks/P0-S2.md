## Goal

Determine exactly how a Remora plugin can answer `approval/request` and `user-questions/request` alongside the dsh web GUI, and pick the withdrawal mechanism for ADR-0008. Answers Q5–Q7.

## Inputs

[ADR-0008](../adr/0008-answer-bridge-race.md), [blueprint §8.6](../blueprint.md#86-answerbridge-approvals-and-questions), upstream `packages/interaction/user-approval/src/index.ts` (`decide`), `packages/interaction/user-questions/src/index.ts`, `packages/api/remotes/src/index.ts` (`forwardWaterfall`), `packages/api/gateway` pending-event handling, `docs/cordis-primer.md` §waterfall.

## Deliverables

- `spikes/p0-s2-answer-bridge/`: bundle with a root-context `prepend: true` listener for both events, driven by the mock LLM so a tool call triggers an approval and `ask_user_question` triggers a question.
- Experiments, each with recorded outcome:
  1. no browser connected → does the listener see the request before the terminal default? what does `next()` return?
  2. one browser tab open → ordering between the Remora listener and api-remotes' per-client listener;
  3. Remora answers first → what happens to the browser card? try: (a) substituting a derived `AbortSignal` on the shared request object before `next()`, (b) observing whether the GUI reacts to `approval/decided`, (c) nothing;
  4. browser answers first → Remora observes the resolution of `next()`;
  5. request signal aborted (turn cancelled) → both sides;
  6. preview: fetch the tool call arguments for `callId` via the live `Session` and via `sessionController.inspect`.
- `docs/spikes/P0-S2.md` with a decision table and the recommended AnswerBridge algorithm; ADR-0008 updated (status line + mechanism).

## Acceptance

- [ ] Each experiment reproduced twice; screenshots or logs attached for GUI behavior.
- [ ] A withdrawal mechanism is selected, or the stale-card limitation is documented with an upstream proposal draft (GitHub Discussion text) in the findings.
- [ ] A startup self-check design proves the bridge is ordered first.

## Constraints

- Do not rely on private symbols that are not exported from published `lib/` files.

## Stop and report

- Root listeners do not receive Agent-scoped dispatches at all.

## Verify

Reproduction steps in `docs/spikes/P0-S2.md` run on a clean `remora-dev` profile.
