## Goal

Prove the P2 exit gate automatically (testkit) and manually (real phone), and leave a repeatable device test script for every later release.

## Inputs

Roadmap P2 exit gate, blueprint §11.1–§11.3, §13.

## Deliverables

- e2e scenarios: pair (confirm/reject/timeout), list, follow from scratch, follow with `afterSeq`, prompt queue/steer, live stream → settlement, cancel, relay restart mid-stream (no gaps), host restart (session resumes cold), duplicate prompt.
- `docs/runbooks/device-test.md` completed for P2: prerequisites, steps, expected results, where to find logs on each side.
- A run of the device script on the owner's phone recorded in `docs/agent-handoffs/P2-T1.md` (owner performs the physical steps if the agent cannot).

## Acceptance

- [ ] All scenarios green in CI (Linux) three runs in a row (flake check).
- [ ] Device script executed once end to end with results recorded.

## Stop and report

- A scenario fails because of a spec gap rather than a bug.

## Verify

```sh
pnpm test:e2e
```
