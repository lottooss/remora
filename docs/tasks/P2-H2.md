## Goal

Serve every session method in [RCP/1 §5](../specs/rcp-v1.md#5-sessions) by calling dsh in-process through `ctx.typertGateway`, mapping dsh events to the RCP `SessionEvent` vocabulary, with coalescing, truncation, paging, and backpressure per blueprint §8.4–§8.5.

## Inputs

RCP/1 §5; blueprint §8.4–§8.5, §11.3; `docs/spikes/P0-S1.md`; fixtures in `packages/host/test/fixtures/dsh-0.1.5-rc.3/`.

## Deliverables

- `adapter/gateway.ts` typed wrappers (unary + stream with cancellation); error mapping table.
- `adapter/sessions.ts`: list (paging cursor), search, follow (snapshot packing ≤ 48 KiB, `afterSeq` resume, reset), page, eventText, toolOutput, prompt (requestId passthrough + host dedupe cache), cancel, queue.update, rename, selectModel, control, models.catalog.
- `adapter/event-map.ts` + `adapter/live.ts` (coalescing every `streamCoalesceMs`, attempt settlement, drop-under-backpressure for live only).
- Streams open only while a device follows; all dsh iterators closed on RCP cancel, channel loss, or dispose.
- Tests: mapper against every fixture file; size packing; resume with and without a gap; duplicate prompt; error mapping; backpressure.

## Acceptance

- [ ] Every RCP §5 method implemented; unknown dsh events become `unknown`.
- [ ] e2e: testkit device lists, follows, prompts (mock LLM), sees live deltas and the settled message, cancels a running turn.
- [ ] No durable event lost or duplicated across a forced relay reconnect mid-stream.

## Constraints

- Only `src/adapter/**` imports `@deepseek-ai/*`. Durable events are never dropped.

## Stop and report

- A needed operation has no gateway endpoint (propose a documented direct service call).

## Verify

```sh
pnpm -F @remora/host test && pnpm test:e2e -t sessions
```
