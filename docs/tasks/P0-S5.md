## Goal

Prove the approval gate end to end on the owner's phone: generate a non-exportable EC P-256 Keystore key that requires a fresh `BIOMETRIC_STRONG` authentication per use, sign the canonical approval message inside `BiometricPrompt` with a `CryptoObject`, and verify the DER signature in Node with `@noble/curves` (high-S accepted).

## Inputs

[ADR-0007](../adr/0007-biometric-gated-parity.md), [Crypto/1 §7](../specs/crypto-v1.md#7-approval-signatures), Android docs: `KeyGenParameterSpec` (`setUserAuthenticationRequired`, `setUserAuthenticationParameters(0, AUTH_BIOMETRIC_STRONG)`, `setInvalidatedByBiometricEnrollment`, `setIsStrongBoxBacked`), `BiometricPrompt.CryptoObject(Signature)`, key attestation.

## Deliverables

- `spikes/p0-s5-approval-key/android/`: single-activity debug app: create key (StrongBox if available, else TEE), show attestation summary, sign a fixed canonical message behind BiometricPrompt, display b64u SPKI and signature.
- `spikes/p0-s5-approval-key/node/verify.mjs`: verifies the pasted SPKI + signature + message with `@noble/curves/p256` (`prehash: true`, `lowS: false`, `format: 'der'`).
- `docs/spikes/P0-S5.md`: device matrix (owner's phone model, Android version, StrongBox yes/no, attestation chain root), behavior when a fingerprint is added (key invalidated?), behavior with device credential only, timings, and the recommended `:core:security` API.

## Acceptance

- [ ] Signature verifies in Node for ≥ 20 signatures, including at least one high-S signature (or evidence that the device always produces low-S).
- [ ] Signing without biometric authentication fails.
- [ ] Adding a new fingerprint invalidates the key (or the finding explains the device's behavior).

## Constraints

- minSdk 28; no third-party crypto on Android for this spike.

## Stop and report

- The owner's phone lacks `BIOMETRIC_STRONG` support (then evaluate the `biometric-or-credential` fallback in ADR-0007).

## Verify

Instructions in the findings file; the Node verifier runs with `node verify.mjs <spki> <sig> <message-file>`.
