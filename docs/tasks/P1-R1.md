## Goal

Implement [RLY/1](../specs/relay-v1.md) §2–§7 and §9–§11 on Cloudflare Workers + the `AccountHub` Durable Object (push is P5-R1).

## Inputs

RLY/1 (frozen), Crypto/1 §2 and §4, `docs/spikes/P0-S3.md`, blueprint §9.

## Deliverables

- Worker routing, `AccountHub` DO with SQLite schema migrations (blueprint §9.2), WebSocket hibernation handlers, auto-response ping/pong, challenge/auth, enrollment endpoints (host secret, device ticket), tickets, links, routing with header rewrite, presence, revoke, endpoint list, limits (frame size, token bucket, endpoint cap, auth timeout), close codes.
- Structured counters (connections, frames, bytes, errors by code) logged without ids beyond 6 characters.
- Tests with `@cloudflare/vitest-pool-workers`: every control frame, enrollment happy/negative paths, routing between linked/unlinked endpoints, newest-wins, revoke closes sockets, oversize/rate-limit behavior, hibernation round-trip.

## Acceptance

- [ ] All RLY/1 vectors pass (`conformance/vectors/relay/**`).
- [ ] No code path reads data-frame payload bytes beyond the 28-byte header (review + test with random payloads).
- [ ] `wrangler deploy --dry-run` succeeds; `wrangler.jsonc` documents every var and secret.

## Constraints

- No payload logging; constant-time secret comparison; SQLite writes throttled as specified.

## Stop and report

- A free-plan limit makes a spec rule impossible.

pnpm -F @remora/relay run typecheck && pnpm -F @remora/relay test && pnpm -F @remora/relay exec wrangler deploy --dry-run
