## Goal

Keep-awake on Windows looks for `globalThis.koffi`, which never exists, so it silently does nothing. Implement it for real.

## Inputs

- docs/SWARM.md (whole file)
- AGENTS.md
- spikes/p0-s6-always-on/ and docs/spikes/P0-S6.md (validated mechanism)
- docs/adr/0009-always-on-host.md
- blueprint §8.11

## Deliverables

- Load `koffi` via `import('koffi')` (add dependency; bundled per P7-H8 rules or kept external — verify it loads inside dsh), call `SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED)` while held and `ES_CONTINUOUS` to release; if koffi cannot load, log a warning once and fall back to a helper process from the P0-S6 spike.
- Workflow `keepawake-windows.yml` (owner approves): on windows-latest, run a script that holds the request via the module and asserts `powercfg /requests` lists the node process under SYSTEM, then releases and asserts it is gone.

## Acceptance

- [ ] Windows workflow green with the `powercfg /requests` output in the log (paste link).
- [ ] No `globalThis.koffi`.
