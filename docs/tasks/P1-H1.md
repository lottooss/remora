## Goal

Turn `packages/host` into a real dsh bundle that loads in a `remora` profile, creates and stores its identity, enrolls and connects to the relay, accepts Noise sessions from paired devices, and serves the RCP core (`hello`, `ping`, `host.status`) with limits.

## Inputs

[blueprint §8.1–§8.3](../blueprint.md#8-remora-host-remorahost), `docs/spikes/P0-S1.md`, dsh-integration §2–§3, §7, RCP/1 §2–§4, Crypto/1 §3, §6.

## Deliverables

- `package.json` as a dsh bundle (`dsh.bundle.patch`, peers on `@deepseek-ai/cordis` + `@deepseek-ai/schemastery`, type-only dev deps pinned to the baseline), `cordis.patch.yml` with the row from blueprint §8.1.
- `src/config.ts` schemastery `Config` + explicit `resolve()` (fails loudly: empty `relayUrl`, relative roots, non-https relay except loopback in dev).
- `src/identity/*` credentials-backed host identity; `src/relay/*` enrollment + `RelayLink` wiring; `src/channel/*` responder handshake, device lookup, channel table, rekey policy, flood limits; `src/rcp/*` envelope handling, method registry dispatch (unimplemented methods → `unknown_method`), stream bookkeeping and cancellation, size and rate limits.
- Device registry interface (storage domain) with an in-memory test implementation; real pairing arrives in P2-H1.
- Build: `tsc` → `lib/` ESM; `pnpm -F @remora/host run build`; install doc in `packages/host/README.md`.

## Acceptance

- [ ] `dsh plugin --profile remora-e2e add ./packages/host` then `dsh --profile remora-e2e --no-open` loads the plugin with no errors; `--dump-config` shows the row.
- [ ] Unit tests: config resolution, handshake admission (unknown key dropped, revoked dropped), RCP dispatch, limits, disposal (no handles after dispose).
- [ ] With a device pre-registered in the test registry, the testkit (P1-T1) completes `hello` through a local relay.

## Constraints

- Only `src/adapter/**` and `src/interaction/dsh-*.ts` may import `@deepseek-ai/*` (enforced by an oxlint/ESLint import rule or a test).
- Every registration via `ctx.effect()`/`ctx.on()`.

## Stop and report

- dsh refuses the bundle or a required service is missing in the `web` template.

## Verify

```sh
pnpm -F @remora/host run build && pnpm -F @remora/host test
```
