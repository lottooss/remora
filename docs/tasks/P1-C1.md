## Goal

Production-quality TypeScript implementation of every construction in [Crypto/1](../specs/crypto-v1.md), promoted from the P0-S4 spike, with the complete vector set that Kotlin must also pass.

## Inputs

Crypto/1 (frozen), `docs/spikes/P0-S4.md`, `docs/spikes/P0-S5.md` (DER/high-S facts).

## Deliverables

- `packages/crypto/src/noise/*`: `Noise_IKpsk2_25519_ChaChaPoly_SHA256` initiator and responder with Remora prologue/PSK helpers; transport `CipherState` with rekey counters; explicit error types.
- `packages/crypto/src/ids.ts` (endpoint ids), `relay-auth.ts`, `pairing.ts` (QR build/parse, `pairPsk`, SAS), `approval.ts` (digest, canonical message, P-256 DER verify with high-S), `push.ts` (seal/open), `random.ts`, `b64u.ts`, `base32.ts`.
- Vector generator `packages/crypto/scripts/gen-vectors.ts` producing every file listed in Crypto/1 §11 from fixed test keys; committed vectors.

## Acceptance

- [ ] Cacophony IKpsk2 vectors and all Remora vectors pass.
- [ ] Negative vectors: tampered ciphertext, wrong PSK, wrong prologue, unknown responder key, high-S accepted, low-order point rejection behavior documented.
- [ ] ≥ 95 % line coverage; no `any`; secrets zeroized where the API owns them.
- [ ] Works in Node and workerd (relay needs `ids` and `relay-auth` verification).

## Constraints

- Only `@noble/curves`, `@noble/ciphers`, `@noble/hashes` as dependencies. No logging.

## Stop and report

- A vector disagrees with the spec text.

## Verify

```sh
pnpm -F @remora/crypto run typecheck && pnpm -F @remora/crypto test && pnpm run conformance:check
```
