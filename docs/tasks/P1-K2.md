## Goal

Move the skeleton from the cached 2024 toolchain to current stable versions and build the app shell every feature plugs into: navigation graph, theme, Hilt wiring, app-lock gate placeholder, diagnostics screen placeholder.

## Inputs

[ADR-0005](../adr/0005-native-android-client.md), [blueprint §10](../blueprint.md#10-remora-for-android-appsandroid), `apps/android/README.md`.

## Deliverables

- Version catalog updated to current stable AGP, Kotlin (+ Compose compiler plugin), Compose BOM, Hilt, KSP, Room, OkHttp, kotlinx.serialization, Tink, Biometric, CameraX, ML Kit barcode, Firebase BOM (dependency declared, plugin applied only when `google-services.json` exists); compileSdk/targetSdk to the current platform; Gradle wrapper updated. Record the SDK packages the owner must install (the agent must not accept SDK licenses on the owner's behalf).
- Navigation: `Pair`, `Hosts`, `Sessions`, `Conversation/{sessionId}`, `NewSession`, `Files/{sessionId}`, `Approvals`, `Settings` destinations with placeholder screens in their feature modules.
- Material 3 theme (dynamic color + dark), typography, `core:ui` status components.
- Module dependency rules enforced (a Gradle check or documented review rule).

## Acceptance

- [ ] `./gradlew assembleDebug testDebugUnitTest` passes locally and in CI.
- [ ] App launches on the owner's phone and navigates between placeholder screens.
- [ ] `android:allowBackup="false"` and data-extraction rules excluding all data are in the manifest.

## Constraints

- Features never import OkHttp, Room, or Keystore APIs directly.

## Stop and report

- A dependency upgrade requires a minSdk above 28.

## Verify

```sh
cd apps/android && ./gradlew assembleDebug testDebugUnitTest
```
