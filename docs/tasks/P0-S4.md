## Goal

De-risk the secure channel: minimal `Noise_IKpsk2_25519_ChaChaPoly_SHA256` handshake + transport in TypeScript (`@noble/*` 2.x) and Kotlin (BouncyCastle), both passing the official Cacophony vectors for that protocol name, and interoperating with each other.

## Inputs

[ADR-0004](../adr/0004-noise-ikpsk2-secure-channel.md), [Crypto/1 §6](../specs/crypto-v1.md#6-secure-channel-sc1), the Noise Protocol Framework specification rev. 34 (§5 processing rules, §9 PSK modes), the Cacophony vector file (import only the `Noise_IKpsk2_25519_ChaChaPoly_SHA256` cases into `conformance/vectors/crypto/noise-cacophony-ikpsk2.json`, with source URL and license noted).

## Deliverables

- `spikes/p0-s4-noise/ts/` and `spikes/p0-s4-noise/kotlin/` (plain Gradle JVM project) implementations: `CipherState`, `SymmetricState`, `HandshakeState` for the IKpsk2 pattern only.
- Vector runners in both languages.
- A cross-language test: Kotlin initiator ↔ TypeScript responder over stdin/stdout (or loopback TCP) exchanging 1,000 transport messages both ways.
- `docs/spikes/P0-S4.md`: API sketch for `@remora/crypto` and `:core:crypto`, pitfalls found (nonce encoding, empty payload handling, PSK token position), performance numbers.

## Acceptance

- [ ] All imported Cacophony cases pass in both languages.
- [ ] Cross-language handshake and 1,000-message exchange pass; tampering with one byte fails decryption.
- [ ] No primitive implemented by hand (only the Noise state machine).

## Constraints

- Constant-time comparisons for MACs; zeroize ephemeral secrets after `split()`.

## Stop and report

- A primitive is unavailable or behaves differently across libraries (e.g. ChaCha20-Poly1305 nonce layout).

## Verify

```sh
cd spikes/p0-s4-noise/ts && pnpm test
cd spikes/p0-s4-noise/kotlin && ./gradlew test
```
