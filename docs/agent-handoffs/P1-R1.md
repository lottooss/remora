## Summary

Promoted the proven P0-S3 relay mechanics into production `apps/relay` (`AccountHub` Durable Object + Worker routing) implementing RLY/1 §2–§7 and §9–§11:
1. **Durable Object & SQLite Data Model:**
   - Real SQLite schema migrations across `endpoints`, `links`, `tickets`, `counters`, and `tasks`.
   - Native Cloudflare DO WebSocket Hibernation with `acceptWebSocket` and `deserializeAttachment`.
   - Zero-overhead auto-response ping/pong keepalives (`{"t":"ping"}` ↔ `{"t":"pong"}`) that never wake the DO.
2. **Authentication & Enrollment:**
   - Host enrollment (`POST /v1/enroll/host`): constant-time bearer secret check against `REMORA_ENROLL_SECRET`, 32-byte Ed25519 public key ingestion, idempotent endpoint registration deriving `h_` IDs.
   - Host ticket issuance (`enroll.ticket` control frame): cryptographically secure 32-byte ticket generated, hashed with SHA-256, and stored with 10-minute expiry.
   - Device enrollment (`POST /v1/enroll/device`): atomic ticket lookup, validation, and single-use invalidation; links host and device endpoints; rejects invalid or re-used tickets with `410 ticket_invalid`.
   - In-band challenge/response authentication: 32-byte challenge nonce signed using `@remora/crypto`'s `verifyRelayChallenge` (Ed25519); fails closed with `4401` on invalid signatures.
3. **Data Frame Routing & Header Rewrite:**
   - 28-byte binary data frame routing between linked endpoints.
   - **Strict Invariant Maintained:** Rewrites only the 17 peer bytes (peer kind + raw 16-byte base32 peer ID: destination → source). Never parses or reads payload bytes beyond byte 28.
   - Fail-closed routing: drops frames and returns `not_linked` for unlinked peers, `peer_offline` for offline peers, and `too_large` for frames > 64 KiB.
4. **Lifecycle & Limits:**
   - Explicit newest-wins connection replacement on concurrent connects via `4409` (`Client Replaced`).
   - Token-bucket per-connection rate limiting (50 msg/s, burst 100).
   - Presence broadcast (`presence` frame) to online linked peers on connect/disconnect.
   - Revocation (`endpoint.revoke`): closes active sockets with `4403` and broadcasts offline status.
5. **Testing & Verification:**
   - 12 comprehensive unit and integration tests executing directly inside `workerd` via `@cloudflare/vitest-pool-workers`.
   - Verified `wrangler deploy --dry-run` with complete binding definitions.
