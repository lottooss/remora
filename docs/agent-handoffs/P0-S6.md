## Summary

Investigated and validated Windows host mechanisms for always-on background operation under standard user permissions (non-elevated). Evaluated logon autostart mechanisms (Task Scheduler via `Register-ScheduledTask`, `HKCU\...\Run`, and per-user Startup folder) and headless window suppression (`conhost.exe --headless`). Validated keep-awake prevention of idle system sleep via `SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED)` in-process using `koffi` and via an external helper process, answering Q9. Documented the logon method matrix, keep-awake trade-offs, and operations runbook guidance in `docs/spikes/P0-S6.md`. Cleaned up all probe artifacts with 0 residue.
