## Summary

Implemented the Android file tree browser, source code viewer with virtualized line paging and syntax highlighting, and git changes / diff viewer in `:feature:files`, `:core:ui`, and `:core:data`. Users can browse session workspace directories with lazy loading, size badges, and binary file indicators. The code viewer (`CodeView`) renders in a virtualized `LazyColumn` for high performance with 20,000+ lines, line gutters, soft-wrap toggle, keyword/token syntax highlighting, search matching, and line pagination. The diff viewer (`DiffView`) renders unified diffs with colored hunk additions and deletions, responsive side-by-side mode, and hunk pagination. All UI layers are fully decoupled from `:core:transport` and `RcpClient`, interacting exclusively through `FilesService` in `:core:data`.
