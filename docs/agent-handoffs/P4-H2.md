# Agent handoff: P4-H2 — Files and diffs (hardened git runner)

## 1. What was done

- **Hardened Git Adapter (`packages/host/src/adapter/git.ts`):**
  - Created `GitAdapter` implementing a security-hardened git execution environment:
    - Guaranteed security flags on all git invocations: `-c core.fsmonitor=false -c core.hooksPath=<isolated empty temp dir> --no-optional-locks --no-ext-diff --no-textconv --no-color`.
    - Spawns strictly in the canonical workspace directory with a 5 s timeout and 1 MiB max buffer cap.
    - Zero execution of hostile repository configurations (`core.fsmonitor`, `diff.external`, `filter.*.textconv`).
    - Robust `-z` porcelain v2 status parser extracting branch headers and file statuses (`M`, `?`, `R`, `D`).
    - Unified diff parser with binary file detection and hunk pagination (budget capped at 36 KiB to ensure RCP messages stay bounded well below 48 KiB).
- **Files Adapter (`packages/host/src/adapter/files.ts`):**
  - Implemented `FilesAdapter` strictly enforcing `PolicyGuard` path containment (`workspaceRoot ∪ remoteRoots`):
    - Rejects path traversal and external paths with `forbidden` (`outside allowed roots`).
    - Enforces 5 MiB read cap on `files.read` (`too_large`).
    - Checks for NUL bytes in text files and rejects binary files in `files.read` (`invalid_params`).
    - Implemented `files.read` (line-paged with offset, limit, version, and eof).
    - Implemented `files.readBytes` (chunked byte reads with base64url encoding).
    - Implemented `files.list` (sorted entries with kind `'dir' | 'file' | 'link'`).
    - Implemented `files.stat` (path, version, bytes).
    - Implemented `files.changes` (live workspace file change notifications stream).
    - Implemented `diffs.status` with fallback: uses `git status` when inside a git repository; falls back to files touched by write/edit tool calls in session history when git is missing or repository is non-git.
    - Implemented `diffs.file` and `diffs.get` with hunk paging.
- **Gateway Adapter Extensions (`packages/host/src/adapter/gateway.ts`):**
  - Added typed wrappers and error mappings for `workspaceFiles/*` methods: `gatewayWorkspaceFilesRead`, `gatewayWorkspaceFilesReadBytes`, `gatewayWorkspaceFilesStat`, `gatewayWorkspaceFilesList`, `gatewayWorkspaceFilesChanges`.
- **RCP Method Handlers (`packages/host/src/rcp/methods/files.ts`, `packages/host/src/rcp/methods/diffs.ts`):**
  - Registered unary handlers `files.read`, `files.readBytes`, `files.list`, `files.stat`.
  - Registered streaming handler `files.changes`.
  - Registered unary handlers `diffs.status`, `diffs.get`, `diffs.file`, `diffs.hunk`.
- **Plugin Exports & Wiring (`packages/host/src/index.ts`):**
  - Exported `GitAdapter`, `FilesAdapter`, and registration functions.
  - Automatically wired into Cordis plugin lifecycle.
- **Unit & Security Tests (`packages/host/test/files-diffs.test.ts`):**
  - 15 comprehensive unit tests:
    - Hostile repository config neutralization: canary files (`canary-fsmonitor.txt`, `canary-diff-external.txt`, `canary-textconv.txt`) are verified NEVER to execute.
    - Porcelain v2 `-z` status parsing.
    - Binary diff detection.
    - Hunk pagination over budget.
    - PolicyGuard security containment and path traversal denial.
    - 5 MiB read cap enforcement.
    - NUL byte rejection.
    - Non-git session write-tool fallback.
    - RCP message dispatch integration for files and diffs methods.
- **End-to-End Test (`tests/e2e/files.spec.ts`):**
  - Real end-to-end test connecting a `FakeDevice` through the relay and opening an encrypted Noise IKpsk2 channel.
  - Device performs `files.stat`, `files.read`, `files.list`, `diffs.status`, and `diffs.file`.
  - Invariant verification: Hostile git configurations (`core.fsmonitor`, `diff.external`) in the workspace are completely neutralized and canary files are never created.
