## Summary

Implemented the `@remora/testkit` package and end-to-end testing harness. This includes `FakeDevice` (a simulated TypeScript client that speaks RLY/1, SC/1 Noise IKpsk2, and RCP/1 with typed RPC invocation), `AdversaryRelayProxy` (an intercepting WebSocket proxy capable of dropping, bit-flipping, replaying, and splicing frames), `MockLlmServer` (an OpenAI-compatible HTTP server providing `/v1/chat/completions` and `/v1/models`), and `E2eEnvironment` (an orchestrator managing local relay, mock LLM, and dsh profile processes with guaranteed teardown). Added the complete smoke test in `tests/e2e/smoke.spec.ts` exercising relay enrollment, WebSocket auth, Noise IKpsk2 channel establishment, and RCP `hello`, `ping`, and `host.status` round-trips.
