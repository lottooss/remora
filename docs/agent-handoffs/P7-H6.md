## Summary

The Windows driver loads the pinned `koffi` package with `import('koffi')`, then acquires and releases the Windows execution state synchronously on the same Node thread. Its acquired flag reflects a confirmed OS request. Release cancels pending loading, the manager handles grace periods during asynchronous startup, and disposal ignores late status events.

Native failure logs one fixed warning through `ctx.logger` and starts a hidden PowerShell helper. One C# call acquires and holds on the same thread, confirms readiness only after a nonzero Windows result, and releases on stdin EOF. Parent-process death closes that pipe, preventing orphan holds. Startup has a ten-second limit, failure does not claim acquisition, helper output is never logged, and release/reacquire during child shutdown preserves the latest request.
