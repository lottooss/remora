## Summary

Implemented the Android new-session flow and host root directory browser in `:feature:workspace` backed by `:core:data`. The user can select from registered workspaces (with `remoteAllowed` badges and recent sorting) or browse allowed host roots via `fs.browse` with breadcrumbs navigation and folder filtering. Users can create new directories via a single-segment validated dialog (`fs.mkdir`), pick an LLM model, compose an initial prompt, and trigger atomic session initialization (`sessions.create` + `sessions.prompt` with idempotency `requestId`s). In accordance with AGENTS.md §7.5 and blueprint §10.2, `:feature:workspace` is fully decoupled from `:core:transport` and `RcpClient`, interacting exclusively through `WorkspaceService` in `:core:data`.
