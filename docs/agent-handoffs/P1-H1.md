## Summary

Implemented the foundational architecture of the `@remora/host` Cordis plugin for dsh. The host plugin now provides credentials-backed host identity generation and storage, an in-memory device registry, Noise IKpsk2 responder handshake admission and channel management, rate-limited and bounded RCP/1 server dispatch (`hello`, `ping`, `host.status`), and relay link integration with graceful Cordis disposal.
