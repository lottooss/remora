The packed tarball cannot be installed: its manifest lists the unpublished workspace
packages `@remora/crypto`, `@remora/protocol`, `@remora/relay-link` as runtime
dependencies, and `npm install` of the tarball fails with npm error 404.

  "@deepseek-ai/cordis": "^4.0.2",
  "@deepseek-ai/schemastery": "^3.18.2"

Installing the tarball (real dsh does `dsh plugin add`, which installs the tarball):

```sh
npm install "<abs path>/remora-host-1.0.0.tgz" --prefix "$(mktemp -d)" --no-save --loglevel=error
# exit code 1, real output excerpt:
npm error 404  The requested resource '@remora/crypto@1.0.0' could not be found or you do not have permission to access it.
```

This matches the audit finding "Documented tarball install cannot work" (SWARM.md §0) and
dsh-integration.md Q10's recommendation that the packed tarball be the install form — which
requires the tarball to be self-contained.
