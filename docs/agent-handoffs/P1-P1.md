## Summary

Implemented complete `@remora/protocol` wire contracts for both RCP/1 and RLY/1:
1. **RCP/1:** zod-validated envelope (`Message` discriminated union with `passthrough()` for unknown fields), `RcpError` model with standard error codes and `createRcpError`, `SessionEvent` union with unknown-value and unknown-kind fallbacks, schemas and types for every method in the RCP method registry (`RCP_METHODS` and `RCP_METHODS_BY_NAME`), and shared ID schemas.
2. **RLY/1:** control frame schemas (`Challenge`, `Auth`, `Ready`, `Ping`, `Pong`, `Presence`, `EnrollTicket`, `EndpointList`, `EndpointRevoke`, `Push`, `PushResult`, `PushToken`, `Bye`, `Ok`, `Error`), close codes (`CloseCodes`: 1000, 4400, 4401, 4403, 4404, 4408, 4409, 4429), and binary data-frame codec (`encodeDataFrame` / `decodeDataFrame` implementing the 28-byte binary header using `Uint8Array` / `DataView` with zero `Buffer` / `node:*` usage).
3. **Limits:** `MAX_RCP_MESSAGE_BYTES = 49152`, `MAX_DATA_FRAME_BYTES = 65536`, `DATA_FRAME_HEADER_BYTES = 28`, `MAX_ENDPOINTS = 32`, `TICKET_TTL_MS = 600000`, `AUTH_TIMEOUT_MS = 10000`, `HOST_OFFLINE_ALERT_MS = 120000`.
4. **Testing:** 63 Vitest tests passing across limits, relay codecs, constants, and RCP method registries. Fully runtime-neutral (safe in both Node and Cloudflare Workers / workerd).
