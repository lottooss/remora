## Summary

Implemented the host-side enforcement layer of ADR-0007 and blueprint §8.7:
1. `policy/paths.ts`: robust Windows-hard path canonicalization and root containment resolving `realpath`, Windows long paths (`\\?\`), case folding, 8.3 short name expansion via native realpath, trailing dot/space handling, NUL/control character rejection, Alternate Data Stream (ADS) rejection, and UNC/device path rejection.
2. `policy/risk.ts`: pure-function deterministic risk classifier with configurable low-risk tool set, destructive command patterns parsed with a shell-aware tokenizer (bash & PowerShell handling quotes, pipes, subshells, chaining), write tools checking target path against workspace root, and unknown tools defaulting to `high`.
3. `policy/signature.ts`: biometric ECDSA P-256 signature verification over canonical approval messages (accepting DER high-S signatures), freshness check (+/- 5 minutes), `argsDigest` check, and `SingleUseApprovalStore` preventing replays.
4. `policy/limits.ts`: per-device token-bucket rate limiter enforcing 20 req/s burst, 5 mutating req/s, and 10 concurrent streams cap.
5. `policy/index.ts`: `PolicyGuard` interface and `DefaultPolicyGuard` implementation consumed by RCP methods and host plugin.
6. Exhaustive test suite in `packages/host/test/policy.test.ts` (98 tests) covering Windows directory junction escapes created via `mklink /J`, traversal escapes, 79 classifier table test cases, signature positive/negative vectors, and token buckets.
