## Summary

Implemented the `remora` CLI command suite (`service install/uninstall/status/logs`, `host run` supervisor, and `doctor`) in `apps/cli`, along with platform keep-awake management (`packages/host/src/platform/**`) per ADR-0009 and spike P0-S6.
The host supervisor runs non-elevated under `%LOCALAPPDATA%\Remora`, managing dsh child processes with exponential capped restart backoff and 14-day daily log rotation. Windows logon autostart uses windowless `conhost.exe --headless` (via Task Scheduler / `HKCU\Run`). `remora doctor` verifies Node 24+, dsh installation, profile existence, bundle registration, relay reachability, service status, and keep-awake support with actionable remediation hints. In `@remora/host`, `KeepAwakeManager` tracks live `agent/status` events, holding keep-awake locks while agents are busy, applying a 2-minute grace period when idle, and releasing cleanly upon Cordis plugin disposal.
