## Summary

The host identity — the Ed25519 relay seed and the Noise X25519 static key (crypto-v1.md §3) — now persists in the dsh credentials record `remora/host-identity` instead of being regenerated on every start, so restarting dsh no longer breaks every pairing. `loadOrCreateHostIdentity(credentials)` (packages/host/src/identity/credentials.ts) reads the record; when absent it generates fresh keys and stores them through `modifyRecord`'s atomic create-if-absent contract, adopting the winner of a concurrent create race; a stored record it cannot parse fails closed with `HostIdentityRecordError` rather than being regenerated (regeneration would silently rotate the host key). `apply()` is now async — verified that Cordis 4.0.2 accepts a promise-returning `apply` (fiber stays pending until the promise settles; a rejection fails the plugin loudly and is logged) — and awaits the identity before anything that needs it. The Integrator addendum is also in: the raw gateway is wrapped exactly once with P7-H9's `RetryingGateway` and handed to the adapters, so the H9 startup-race retry is no longer dead code. The H1 console bridge is untouched.
