## Deviations from the packet

1. **Parser ordering fix in commit 2** (`test/spec-method-table.ts`): the commit-1 parser appended §7 devices methods after §10 instead of walking sections in numeric order, so the parsed list did not follow spec order. Commit 2 fixes the parser to process §4→§10 in order; the assertions are unchanged. The red run's failure reason was the set mismatch, not this bug.
2. **Deleted the `devices.list`/`devices.rename`/`devices.revoke` zod schema groups** rather than leaving them unused: removing them from the registry left those exports with zero consumers anywhere (host, testkit, app). AGENTS.md §7.1 (no dead code) applies; if device management UI ever needs them they come back through the AGENTS.md §6 contract change process.
3. **`packages/protocol/test/rcp.test.ts` oracle updated** to the reconciled 36-method list. This is an update of the expected contract, not a weakening: the test keeps its independent hand-copied oracle (so it still guards against accidental registry churn), and the new spec-parsing test makes the spec the mechanical authority.
4. Commit 2 was amended once (message wording only, no content change) and pushed with `--force-with-lease` on this task branch, which AGENTS.md §9 permits.
