## Summary

Built and measured the throwaway relay spike `spikes/p0-s3-relay/`: a single SQLite-backed `AccountHub` Durable Object with hibernating WebSockets, tag-based routing, byte-exact `setWebSocketAutoResponse` keepalives, newest-wins 4409 replacement, a multiplexed host-offline/auth-deadline alarm slot, and 20:1 request accounting. The two-client Node suite passes **21/21 assertions** (10,000-frame ordered lossless run, oversize/not_linked/peer_offline fail-closed paths, zero-wake keepalives, hibernation with attachment survival, alarm arm/cancel/fire, bad-auth 4401). Measured `wrangler dev` restart behavior: clients get **close 1006 / wasClean=false** and all SQLite state survives. `docs/spikes/P0-S3.md` records the evidence, the free-plan streaming-hour math (≈1,275–1,325 billed requests/h ≈ 1.3 % of quota at ADR-0002's ≤7 msg/s), and eight RLY/1 recommendations for P0-A2 (no wire changes).
