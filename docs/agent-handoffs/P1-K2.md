## Deviations from the packet

1. **AGP 9 built-in Kotlin:** the `kotlin-android` plugin is intentionally not applied to Android modules (AGP 9.x provides Kotlin); the catalog's `kotlin` version only versions pure-JVM modules and the Compose/serialization compiler plugins. Documented in the catalog header and README.
2. **Destinations live in existing feature modules**, not new ones: NewSession → `:feature:workspace`, Approvals/Diagnostics → their blueprint modules (`:feature:conversation`, `:feature:settings`), Hosts → `:feature:sessions` (blueprint §10.2 module list).
3. **`checkModuleDependencyRules` covers project deps + Okhttp/Room/Tink groups** in `:feature:*`; the Keystore half of the constraint (`android.security.keystore` only under `core/security/**`) is a source-review rule (grep) — not expressible in Gradle — documented in README.
4. **README SDK list adds `build-tools;36.0.0`** (AGP 9.4.1's required build tools; observed auto-install).
