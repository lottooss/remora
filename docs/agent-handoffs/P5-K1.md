## Summary

Implemented [ADR-0006](../adr/0006-fcm-data-messages.md), blueprint §10.5, Crypto/1 §8, and RLY/1 §5 (`push.token`):
Receives and displays notifications reliably and privately on Android, with host push key decryption in `RemoraMessagingService`, channel mapping, deep links behind `AppLockGate`, and notification preferences in Settings.

Key components:
1. **Notification Channels & Manager (`apps/android/app/src/main/kotlin/io/github/lottooss/remora/notification/RemoraNotificationManager.kt`):**
   - Channels created on Android O+:
     - `remora_approvals` (Approvals: High importance)
     - `remora_questions` (Questions: High importance)
     - `remora_turns` (Turn Events: Default importance)
     - `remora_errors` (Errors: High importance)
     - `remora_host_offline` (Host Offline: High importance)
   - `showNotification` building `NotificationCompat.Builder` with deep-link PendingIntents targeting `MainActivity`.
2. **Push Payload Decryption & Routing (`apps/android/app/src/main/kotlin/io/github/lottooss/remora/notification/PushPayload.kt`, `RemoraMessagingService.kt`):**
   - `RemoraMessagingService` extending `FirebaseMessagingService` with `@AndroidEntryPoint`.
   - Handles `k == "host_offline"` metadata-only alert: looks up host from `HostRepository` and displays offline warning.
   - Handles ciphertext `ct`: looks up host keys from `KeyStorage`, zeroizes key material after use, decrypts with `openPushPayload(pushKey, decodeBase64Url(ct))` from `:core:crypto`.
   - Drops undecryptable or invalid ciphertext gracefully without crashing or logging secrets.
   - Maps `kind` to channels and constructs deep link URIs (`remora://approvals`, `remora://session/<id>`).
3. **Deep Links & App Lock (`AndroidManifest.xml`, `RemoraNavHost.kt`, `MainActivity.kt`):**
   - Configured `<intent-filter>` for `remora://` scheme in `MainActivity`.
   - Added `navDeepLink`s in `RemoraNavHost` for `remora://approvals`, `remora://approvals/{id}`, `remora://session/{sessionId}`, `remora://conversation/{sessionId}`, and `remora://hosts`.
   - All deep link navigations remain strictly gated behind `AppLockGate` in `MainActivity`.
4. **Settings & Diagnostics Integration (`feature/settings/SettingsScreen.kt`):**
   - Push notifications section in `SettingsScreen`:
     - Displays informational banner when Firebase setup (`google-services.json`) is not present.
     - Toggles for Approvals, Questions, Turn Events, Errors, and Host Offline notifications.
5. **Unit Tests (`apps/android/app/src/test/kotlin/io/github/lottooss/remora/notification/PushNotificationTest.kt`):**
   - Tests encryption and decryption round-trip via `sealPushPayload` and `openPushPayload`.
   - Tests payload parsing and channel/deep-link mapping for all kinds.
   - Tests `HOST_OFFLINE` channel configuration.
   - Tests graceful failure on corrupt/invalid ciphertext and malformed JSON.
