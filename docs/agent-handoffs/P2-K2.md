## Summary

Implemented the Android remote sessions and conversation experience:
- `:core:data`: SessionSummary and SessionEvent domain entities, SessionRepository maintaining bounded 2,000-event histories per session with deduplication and pruning, SyncEngine coordinating sessions.follow with monotonic live delta overlays that retire on durable event settlement and afterSeq resumption, and SessionService enforcing fail-closed offline policy with idempotent prompt retries using the same requestId.
- `:feature:sessions`: SessionsScreen grouping sessions by workspace with real-time status indicators (running/idle/error), live search filtering across title, ID, and workspace, quick action buttons for new sessions and approvals inbox.
- `:feature:conversation`: ConversationScreen rendering history transcripts, markdown styling, copyable code blocks, collapsible tool call cards with truncated argument previews, tool result output cards with clipboard copy, turn markers, live streaming bubbles with typing indicators, model selector dropdown, paging header ("Load older messages"), and bottom composer with Queue vs Steer delivery toggle, prompt sending, turn cancellation, and offline banners.
