## Summary

Implemented Kotlin twin libraries for Android/JVM in pure Kotlin (`kotlin("jvm")`, no Android framework dependencies), matching `@remora/protocol` and `@remora/crypto` with 100% parity against shared conformance vectors:

1. **`:core:crypto` module:**
   - **Codecs:** Hex, RFC 4648 §5 unpadded base64url, RFC 4648 §6 lowercase base32 (`Codecs.kt`).
   - **Noise IKpsk2:** Full BouncyCastle `bcprov-jdk18on` implementation (`Noise_IKpsk2_25519_ChaChaPoly_SHA256`) including `CipherState`, `SymmetricState`, and `HandshakeState` with PSK `e` token key mixing and post-handshake split/zeroization (`Noise.kt`).
   - **Identities:** `deriveEndpointId` for host (`h_`) and device (`d_`) with SHA-256 and base32 encoding (`Ids.kt`).
   - **Relay Auth:** Ed25519 challenge signing and verification (`RelayAuth.kt`).
   - **Pairing:** Pairing QR URI parsing and building (`remora://pair?...`), HKDF-SHA256 PSK derivation (`derivePairPsk`), and HMAC-SHA256 6-digit SAS code derivation (`deriveSasCode`) (`Pairing.kt`).
   - **Approvals:** Canonical message formatting (`buildCanonicalApprovalMessage`) and sorted JSON SHA-256 argument digest (`computeArgsDigest`) (`Approval.kt`).
   - **Push Encryption:** ChaCha20-Poly1305 push payload sealing and opening with 12-byte random nonce prefix and 2048-byte limit (`Push.kt`).

2. **`:core:protocol` module:**
   - **Limits:** Exact normative constants matching `@remora/protocol/limits.ts` (`Limits.kt`).
   - **RLY/1 Data Frame Codec:** 28-byte binary frame encoder/decoder with big-endian byte layout, 16-byte peerId enforcement, and 64 KiB boundary enforcement (`DataFrame.kt`).
   - **RLY/1 Control Frames:** Sealed polymorphic control frames (`Challenge`, `Auth`, `Ready`, `Ping`, `Pong`, `Presence`, `Push`, etc.) with `kotlinx.serialization` discriminator `"t"` and `CloseCodes`/`RelayErrorCodes` (`RelayControl.kt`).
   - **RCP/1 Envelopes:** Sealed `RcpMessage` (`Request`, `Response`, `StreamItem`, `StreamEnd`, `StreamCancel`, `Event`) and `RcpError` with 48 KiB limit checks and unknown field tolerance (`RcpEnvelope.kt`).
   - **Session Events:** Polymorphic `SessionEvent` with safe fallback to `SessionEvent.Unknown(dshType = ...)` for novel types and conservative open-enum fallbacks (`SessionEvent.kt`).

3. **Verification & Testing:**
   - Vector conformance tests loading `conformance/vectors/crypto/*` and `conformance/vectors/rcp/*` and `conformance/vectors/relay/*`.
   - Cacophony vector test for Noise IKpsk2 passing 100%.
   - Full Gradle build: `assembleDebug` and `testDebugUnitTest` passing across all 11 Android modules.
