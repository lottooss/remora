## Summary

Implemented `@remora/relay-link`, a reusable, robust RLY/1 WebSocket client for Node used by the host plugin (`@remora/host`) and the testkit (`@remora/testkit`):
1. **RelayLink class:**
   - Full lifecycle management (`idle` → `connecting` → `authenticating` → `ready` → `backoff` → `stopped`).
   - Challenge/response relay authentication using `@remora/crypto`'s Ed25519 `signRelayChallenge` and `encodeBase64Url`.
   - Control frame request correlation using `rid` with configurable timeout and error mapping.
   - Binary data-frame multiplexing via `@remora/protocol` 28-byte header codecs (`encodeDataFrame` / `decodeDataFrame`).
   - Active heartbeat (ping every 25 s) and dead-peer timeout detection (60 s).
   - Full jitter exponential backoff reconnection (`minBackoffMs: 500` → `maxBackoffMs: 30000`, reset on success).
   - Fail-closed handling for permanent authorization errors (4401 AUTH_FAILED, 4403 FORBIDDEN, 4409 CLIENT_REPLACED) that suppress automatic reconnect.
   - Clean shutdown with `stop()` resolving in < 50 ms, clearing all timers, and rejecting pending requests.
2. **Pluggable WebSocket factory:** Injected `WebSocketClass` allowing testing with custom mock sockets without network access.
3. **Testing:**
   - Reconnect storm test with 100 forced disconnects verifying no leaked sockets/timers.
   - Correlated request-response and error frame propagation.
   - Presence tracking and peer list caching.
   - Binary data-frame encoding and event dispatch.
   - Stop cleanup latency under 500 ms.
