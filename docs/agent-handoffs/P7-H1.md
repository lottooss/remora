## Summary

The host plugin now declares its required dsh services (`export const inject = ['typertGateway', 'credentials', 'storage']`), so Cordis 4 loads it in real dsh instead of crashing with `cannot get property "typertGateway" without inject`. The gateway is read through a typed `ctx.typertGateway` (declaration merging from type-only imports of `@deepseek-ai/dsh-api-gateway`, `@deepseek-ai/dsh-agent`, `@deepseek-ai/dsh-session`, devDeps pinned to `upstream.lock.json` 0.1.5-rc.3); every `(ctx as any)` and the untyped `ctx as unknown as { on(` escape are gone from `packages/host/src/index.ts`; the silent `if (gateway)` branch is removed so the session/workspace/fs methods always register; the three event listeners register through the typed `ctx.on` with handler bodies kept verbatim (retyping them against the real dsh payloads is P7-H5). Because dsh 0.1.5-rc.3's web profile registers no console exporter for the Cordis logger (verified upstream — a plugin's `ctx.logger` output never reaches the terminal), a small console bridge scoped to the `remora` logger name makes the startup/status lines visible, which the P7-G1 gate asserts. The `apply()` harness mounts the real plugin on a real `@deepseek-ai/cordis` Context with fakes only for the dsh side (`typertGateway`, `credentials`, `storage`), provided inside their own plugin fibers the way real dsh provides services.

### Commit 3 (`363dab6`) — console bridge

## Deviations from the packet

1. **Console bridge added to `apply()` (commit 3).** The packet's deliverables do not mention a console exporter, but its acceptance ("dsh survives 45 s and logs `remora: host started`") is unobservable without one: verified against the pinned upstream that dsh 0.1.5-rc.3 never surfaces Cordis logger output on the terminal. The bridge is 12 lines in `index.ts`, uses the official `Logger.format` (no `console.*` — it writes via `process.stdout`, the existing `printTerminalQr` seam), is scoped to the `remora` logger name so all other dsh services stay silent, and is disposed with the plugin fiber. Flagging for the Integrator: if a different visibility mechanism is preferred (e.g. a `logger-console` row in the bundle patch via P7-H8), the bridge is a self-contained 12-line removal.
2. **`pnpm-lock.yaml` regenerated** (root file, outside the packet's `owned_paths`) as the mechanical consequence of adding the three type-only devDependencies to the owned `packages/host/package.json`; without it CI's frozen install cannot run. No other root file touched.
3. **An intermediate commit tried `@deepseek-ai/cordis-plugin-logger-console`** and was replaced within the same PR: its schemastery `~3.18.4` range collides with the exact `3.18.2` pin of the dsh 0.1.5-rc.3 type packages, putting two schemastery copies with conflicting global augmentations into one TS program (broke `packages/testkit` typecheck). The inline bridge avoids the dependency entirely; the host's schemastery devDep stays at the dsh-matching `3.18.2`.
