# @remora/protocol

RCP/1 and RLY/1 wire contracts: exported types, zod schemas for untrusted input, codecs with size limits, the method registry, and the generators for `conformance/vectors/{rcp,relay}`. Runtime-neutral (Node and workerd).

- **Specs:** docs/specs/rcp-v1.md, docs/specs/relay-v1.md
- **Implemented by:** P1-P1
- **Owner role:** protocol-crypto (AGENTS.md §3)
